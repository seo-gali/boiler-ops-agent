# 로컬 Pretendard 글꼴

앱과 프로젝트 안내 페이지는 이 폴더의 `pretendard.css`와 `PretendardVariable.woff2`를 같은 서버에서 제공합니다. 외부 글꼴 CDN에 접속하지 않습니다.

동일한 `Pretendard Variable`이 설치되어 있으면 로컬 글꼴을 먼저 사용해 다운로드를 생략합니다. 없으면 원본 WOFF2를 사용하며 `font-display: swap`으로 글꼴 수신 중에도 본문을 표시합니다. 한글과 원본 센서명 표시 범위를 줄이는 서브셋은 적용하지 않습니다.

- 원본: [Pretendard 공식 v1.3.9](https://github.com/orioncactus/pretendard/releases/tag/v1.3.9)
- 파일: `PretendardVariable.woff2` — 원본 가변 글꼴
- 저작권: Kil Hyung-jin
- 사용 조건: [SIL Open Font License 1.1](OFL.txt)

글꼴 파일을 배포할 때 저작권과 라이선스 파일을 함께 유지합니다. 폰트 이름은 CSS에서 `Pretendard Variable`로 사용합니다.
