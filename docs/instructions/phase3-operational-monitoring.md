# Phase 3 — 실제값·목표값 비교와 변화 확인

온도 분석은 재열기를 대상으로 한다. `최종재열기 입구 온도 평균값`을 실제값, `목표 재열기 온도`를 목표값으로 비교하되 두 값이 같은 지점에서 측정됐다고 설명하지 않는다.
목표 온도는 원본 전체에서 결측이므로 API의 목표 편차도 null이다. 발전량은 실제·목표 모두 존재해 편차를 계산한다. `GET /api/analysis/loop`는 재열기·발전 지표의 동일 시각 비교를 제공하고, `GET /api/analysis/sensor`는 센서별 통계를 제공한다.
관련 제어값은 같은 시각에 받은 값으로 묶는다. 함께 변했다는 이유로 한 값이 다른 값을 바꿨다고 설명하지 않는다.

변화율은 원본 시각(`source_time`)의 경과 분을 기준으로 계산한다. 현재값이 평소 기록에서 얼마나 벗어났는지 계산할 때는 최신값을 제외한 이전 기록을 사용한다. 이 차이를 산업 안전 기준으로 표현하지 않는다.

현재 메인 `기간 조회`는 [원본 기간 비교](phase7-workspace.md#원본-기간-비교-계약) 화면이다. 초기 운전 분석 비교표·실시간 이벤트 표를 다시 배치하지 않는다. 최근 추이는 센서 상세·AI 탐색에서, 재열기 5분 예측은 공장 아래에서 확인한다.

실제 Kafka·브라우저 연결 검사에서 같은 시각의 값끼리 비교되는지 확인한다. 실제값과 목표값의 차이, 빈 값 보존, 과거 기록 수와 통계값, 선택한 설비의 연결도 대조한다.
