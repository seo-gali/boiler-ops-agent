# Phase 4 — 원본 근거로 답하는 AI 조회

로컬 Ollama 모델은 `OLLAMA_BASE_URL`·`OLLAMA_MODEL`로 지정한다. 기본 설정은 `qwen2.5-coder:7b`다. 외부 모델 서비스는 사용하지 않으며 앱 조회에는 운영자 세션 인증이 필요하다.
모델은 허용된 읽기 전용 도구와 답변에 쓸 근거를 고른다. 서버는 기본 상태 조회인 `get_equipment_status`와 모델이 고른 추가 도구를 호출하되 같은 도구를 중복 호출하지 않는다. 자세한 기준은 [질문별 AI 응답](phase7-agent-answers.md)을 따른다.

답변의 숫자는 서버가 실제 근거에서 가져온다. 모델이 숫자를 지어내거나 확인되지 않은 원인을 단정하지 않는다. 질문 대상은 Registry에 등록된 설비·Tag로 고정하며 다른 설비를 둘러봐도 이미 보낸 질문의 대상은 바뀌지 않는다. AI는 CSV·Kafka에 직접 접근하지 않는다.

질문·대상 설비·모델·도구 요청과 결과·근거 ID·최종 답변·실패를 조회 기록(Trace)에 남긴다. 전체 연결 검사에서는 실제 로컬 모델의 답변을 근거 수치와 대조하고, 없는 센서나 쓰기 요청이 허용되지 않는지 확인한다.
