# Phase 5 — 재열기 5분 뒤 온도 예측

`최종재열기 입구 온도 평균값`의 원본 시각 5분 뒤를 예측한다. 현재 온도가 그대로 이어진다고 보는 단순 예측(Naive)과, 현재값에서 5분 뒤 값을 계산하도록 학습한 선형 모델을 비교한다.

데이터를 시간순으로 앞 70% 학습, 다음 15% 검증, 마지막 15% 시험에 쓴다. 각 구간의 경계를 넘는 입력·정답 쌍은 제외한다. 빈 값이나 시간 간격이 맞지 않는 기록도 학습에서 제외한다.

모델은 검증 구간의 평균 절대 오차(MAE)가 작은 쪽을 고른다. MAE는 예측이 실제값에서 평균적으로 얼마나 벗어났는지를 뜻한다. Naive의 오차가 작으면 Naive를 선택한다. 마지막 시험의 MAE·RMSE는 결과 보고에만 쓰고 모델을 다시 고르는 데 사용하지 않는다. RMSE는 큰 오차에 더 민감한 평가값이다.

예측 요청은 학습·검증 종료 이후의 원본 시각(`source_time`)만 허용한다. AI는 `get_temperature_forecast`라는 읽기 전용 도구로 결과를 조회한다.

목표 온도는 원본에 값이 없고 실제 조작 효과도 확인되지 않았다. 예측으로 밸브를 얼마나 움직일지 제안하지 않는다. 전체 연결 검사에서는 시험 구간을 Kafka로 재생해 화면의 예측값을 모델 계산·근거와 대조한다.
