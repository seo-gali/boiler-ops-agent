# Phase 7 — 작업 화면 사용성

## 2026-10-12 수정 계약

아래 계약이 이전의 센서 변경 시 AI 초기화 동작을 대체한다.

```text
계통도·KPI → selectedTag → 설비 분류 → 해당 설비 센서 검색/선택 → 상세
                   │
                   └─ [이 센서로 새 질문] → questionTag 고정 → 요청/답변/Trace
                                              ↑
                             다른 설비 탐색은 questionTag를 바꾸지 않음
고정 대표 Tag → 설비 이름표 (선택 센서와 별도로 유지)
작은 AI 버튼 하나 → 센서 | AI | 기록 도우미 → 접힌 승인 연습
```

- 분류에는 발전 지표와 미분류 항목도 빠짐없이 포함한다. 카테고리 변경은 명시적인 탐색 조작이다.
- 요청 중 센서 탐색이나 패널을 닫았다 다시 열어도 질문을 버리지 않는다. 명시적 대상 변경은 요청 대기 취소 후 가능하다.
- AI/Simulator 예시는 빈 입력의 placeholder 또는 사용자가 선택하는 예시로 제공한다. 비어 있는 요청은 전송하지 않는다.
- 모델 처리 단계나 진행률을 추정하지 않는다. 경과 시간·브라우저 대기 취소·시간 초과·실패·재시도를 사실대로 표시한다.
- 이름표 간 겹침, 작은 Canvas, 확대/축소·이동, 그룹별 센서 수/필터, 진행 중 탐색과 늦은 응답, 빈 요청·오류·취소 및 재시도를 실제 브라우저에서 확인한다.

## 공통 구현 계약

```text
Registry Equipment { id, label, name, description, primary_tag, position, size }
                    ↓ 대표 센서 선택의 단일 기준
도형 / Marker / 설비 목록 → App.selected: 원본 Tag
                                ↓
단일 AI 버튼 → WorkspacePanel: sensor | agent | audit
             ├─ 탐색 센서 변경 → 질문 대상·이전 질문 보존
             ├─ Agent query → answer + trace_id → 패널 안 Trace 조회
             └─ AI 내부 Simulator 펼치기 → 명시적 승인/거절 → 패널 안 Audit 조회

Space + 드래그 → Pan { x, y } ┐
Space + 휠 → Zoom            ├→ 실제 Canvas 카메라 → 설비와 이름표 연결선
버튼 이동 / 초기화            ┘
```

- 센서 선택과 패널 열기는 모델 호출·승인을 실행하지 않는다.
- 데스크톱은 계통도와 비모달 오른쪽 패널을 나란히 사용한다. 모바일은 아래쪽 패널로 전환하고 닫기·Escape·포커스 복귀를 제공한다.
- 패널 탭 이동은 질문과 답변을 보존한다. 센서를 변경하면 이전 요청의 늦은 응답을 새 센서에 붙이지 않는다.
- Space는 계통도 조작 중에만 페이지 스크롤을 막는다. 입력창·버튼의 기본 키보드 동작과 일반 휠 스크롤은 보존한다.
- 키 해제·창 포커스 소실·포인터 취소 때 이동 상태를 해제한다. 드래그 종료를 설비 클릭으로 처리하지 않는다.
- 제공된 `CustomExcelView.xlsx`의 118개 컬럼을 CSV 원본 Tag와 대조해 단위·행 번호를 연결한다. 원본 `degC`는 `°C`로 표기하고 숫자는 환산하지 않는다. 단위 정의 없는 센서는 `unit: null`을 유지한다. 용어집을 해당 센서의 단위표로 취급하지 않는다.

## 실패 검토 및 E2E 완료 기준

| 상황 | 검증할 동작 |
| --- | --- |
| 도형과 라벨의 선택 불일치 | 모든 설비의 대표 Tag·선택 강조·Inspector 값 일치 |
| 화면 크기·줌·이동 변경 | 라벨 겹침 없음, 연결선과 실제 카메라 좌표 일치, 기본 배율에서 구조물 가림 없음 |
| Space 해제·blur·pointercancel | 이동 모드 종료, 일반 휠 스크롤 복구 |
| 입력창 공백·버튼 Space | 입력과 키보드 활성화 보존 |
| 센서 변경 중 AI 응답 | 질문 대상·답변·Trace 보존, 탐색 센서와 질문 대상의 구분 표시 |
| 명시적 질문 대상 변경 | 이전 답변·Trace 초기화, 진행 중에는 대기 취소 후 가능 |
| 패널 탭·닫기·재열기 | 같은 센서 질문 상태 보존, Escape와 포커스 복귀 |
| Trace/Audit 실패·빈 결과 | 오류·재시도·빈 상태 안내, 새 탭·다운로드 없음 |
| 모바일·확대·긴 한글 | 페이지 가로 넘침 없음, 메뉴와 패널 조작 가능 |
| 글꼴 네트워크 차단 | 포함된 로컬 Pretendard로 표시 |
| 단위 미제공 | 원본 값 유지, 임의 단위·환산 없음 |

실제 CSV·Kafka·API·Ollama·Chromium을 별도 포트/임시 계정으로 검증한다. 사용자 실행 환경은 중단하지 않는다. 관찰 가능한 조작·응답·화면 캡처·결과를 `artifacts/e2e/phase7/workspace/`에 저장하며 개인 키·쿠키는 기록하지 않는다.
