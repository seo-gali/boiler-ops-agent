# Phase 7 — 공장 탐색·대화·원본 기간 조회

## 추가 개정 계약

이번 사용자 요청은 기존 작업 화면의 탐색·질문·닫기 동작을 아래 계약으로 바꾼다. 이전 실행 결과는 `docs/results/phase7-workspace.md`에 보존하며 이번 구현의 검증은 `docs/results/phase7-game-chat-history.md`에 기록한다.

```text
공장 모니터링 → 7개 논리 설비 → 해당 설비의 모든 센서 목록
                         ↓
                  설비 → 원본 이름 세부 묶음 → 센서명·값·단위
                  전체 118개 검색 → 선택 센서 상세

원본 이름이 주증기인 지표 → main-steam (5개, 그림 밖 분류)
발전 지표 → generation (2개); 위치 미확인 → unmapped (1개)
그림의 7개 설비 → 110개 센서; 고정 대표 Tag → 대표 이름표

selectedTag: 화면에서 탐색하는 센서
questionTag: 사용자가 질문 대상으로 고정한 센서
Chat turn: 질문 → 독립 API 조회 → 답변·Trace·처리 시간
                 이전 대화 내용은 서버 입력에 자동으로 추가하지 않음

기간 조회 → 센서·시작·끝 → 인증된 원본 CSV 읽기 → 실제 관측점 그래프
5분 예측 → 재열기 예측값·원본 시각·Naive와 시험 성능
```

## 화면과 센서 계약

- 메인 화면은 `공장 모니터링 | 기간 조회 | 5분 예측`으로 나눈다. 반복되는 수신 표는 제거한다.
- 자동 갱신 일시정지 조작은 메뉴 줄, Kafka·WebSocket·재생 간격은 LIVE와 사용자 표시 옆에 둔다. 화면 갱신 일시정지는 서버 수집이나 별도 조회를 멈춘다는 뜻이 아니다.
- 게임 표현은 논리 탐색용 장식이다. 실제 설비 대수·좌표·운전·위험 등급·인과관계를 생성하지 않는다.
- 설비를 누르면 소속 센서 전체를 읽을 수 있는 목록으로 보여준다. 원본 센서명에 따라 급탄기 A~F, 노내 튜브·헤더, 기수분리기, 연소공기·송풍기, 스프레이·과열저감기, 과열·재열 구간 등 세부 묶음을 제공한다.
- 카테고리를 바꾸는 행동은 탐색 범위만 바꾸며 센서 목록에서 명시적으로 골라야 선택이 바뀐다. 현재 선택의 경로를 표시하고 전체 검색·검색 초기화·결과 없음 안내를 제공한다.
- 종류 필터는 접힌 부가 조작이다. 목록에 센서명·현재값·단위·원본 식별자·선택 상태를 표시한다.
- 주증기 압력·유량은 과열기의 실제 설치 센서라는 근거가 없으므로 `main-steam`으로 분리한다. 클릭한 압력과 대표 온도는 다른 측정값이며 단위·이름을 혼동하지 않게 한다.
- Space를 계통도 위에서 누른 동안 드래그 이동·휠 확대를 지원한다. 일반 휠, 입력창의 공백 입력, 버튼 키보드 조작을 보존한다. 키 해제·blur·pointercancel 때 이동 모드를 해제하고 드래그를 클릭으로 처리하지 않는다.
- 118개 단위는 제공된 `CustomExcelView.xlsx`의 원본 Tag·행 번호와 연결한다. 원본 `degC`는 `°C`로 표기하며 숫자·음수·결측은 보정하지 않는다.

## AI 대화와 닫기 계약

- 전역 AI 진입 버튼 하나와 센서 상세의 질문 행동을 제공한다. 조회는 사용자가 질문을 보내야 시작하며 빈 질문은 보내지 않는다.
- 여러 질문과 답변을 순서대로 보존한다. 각 답변은 그때 고정한 센서, 질문, 처리 시간, 원본 시각, Trace와 연결한다. 대화 누적 표시는 서버의 대화 기억 기능을 의미하지 않는다.
- 질문 예시는 센서에 맞게 제시하고 추가 예시는 접어 둔다. Simulator의 빈 입력도 placeholder로 예시를 보여준다.
- 다른 설비 탐색은 진행 중 조회·초안·완료된 답변을 변경하지 않는다. 명시적으로 질문 대상을 바꿀 때 초안을 버릴 수 있으면 먼저 확인한다.
- 닫기 버튼은 X만 보이며 접근 가능한 이름을 제공한다. 초안이나 진행 중 조회가 있으면 내용이 끊길 수 있음을 설명하고 native 확인창을 띄운다. 취소하면 열린 상태를 유지한다.
- 닫기를 승인하면 브라우저의 답변 기다림을 취소하되 초안·대화 기록을 보존한다. 서버의 이미 시작된 작업이 계속될 수 있다는 점을 사실대로 설명한다. Escape도 같은 경로를 사용한다.
- 다른 패널 탭으로 떠날 때 확인이 필요하면 취소 시 이동하지 않는다. 승인한 탭 이동에서는 조회를 계속하고 돌아왔을 때 답변을 확인할 수 있다.
- 경과 시간·취소·시간 초과·오류·재시도를 사실대로 표시한다. 추정 진행률·가상의 모델 처리 단계를 표시하지 않는다.
- Trace·Simulator Audit는 같은 도우미 안에서 읽는다. 승인 연습은 접힌 추가 기능이며 실제 설비 연결이나 직접 밸브 조작을 제공하지 않는다.

## 원본 기간 조회 계약

```text
GET /api/history/metadata → 원본 CSV의 기간·행 수·시간대 정보
GET /api/history/range?tag=…&start=…&end=… → 선택한 기간의 원본 관측점
                                     ↓
OperationsAnalysis → 시간 그래프 + 원본 행/표시 점/결측 안내
```

- 기존 인증 세션을 사용하고 읽기 전용 조회만 제공한다. 원본 CSV·운영 데이터·설정·인증 상태를 변경하지 않는다.
- 기간과 센서를 검증하고 잘못된 기간·빈 결과·요청 실패를 구분해 안내한다. 오류를 빈 정상 그래프로 위장하지 않는다.
- 그래프의 모든 숫자와 시각은 원본 행에서 추적 가능해야 한다. 표시 점 수를 줄이더라도 실제 관측점만 고르며 임의 값이나 평균으로 결측을 채우지 않는다.
- 결측·파싱 실패 구간의 연결선을 끊고 원본 행 수, 반환 점 수와 생략 여부를 구분한다. 현재 재생 데이터와 원본 기간 조회를 같은 상태로 설명하지 않는다.
- CSV를 읽는 동안 파일이 변경되거나 행별 시간대 오프셋이 달라지면 조회를 거부한다. 이번 원본은 시간대 정보가 없으며 임의로 한국 시간이나 UTC로 해석하지 않는다.
- 신규 의존성을 추가하지 않고 기존 React·SVG와 Python CSV 처리로 구현한다.

## 실패 검토와 E2E 완료 기준

| 상황 | 실제로 확인할 동작 |
| --- | --- |
| 주증기 KPI 클릭 | `main-steam` 분류·원본값·단위 표시, 과열기 온도로 선택하지 않음 |
| 설비별 전체 목록 | 110 + 5 + 2 + 1 = 118개 누락 없음, 원본 이름 묶음·전체 검색 |
| 센서 목록 선택 | 원본 Tag·현재값·단위·선택 경로와 Inspector 일치 |
| 게임 표현·모바일·줌 | 조작 가능, 라벨·전체 센서 목록 읽기 가능, 가로 넘침 없음 |
| AI 여러 질문 | 독립 서버 호출과 근거 대조, 이전 질문·답변 보존 |
| 조회 중 다른 설비 탐색 | 질문 대상 고정, 늦은 답변을 탐색 센서에 붙이지 않음 |
| 초안·대기 중 X/Escape | 확인 취소 시 유지, 승인 시 대기 취소·초안·기록 보존 |
| 패널 탭 이동 | 확인 취소 시 유지, 승인 시 조회 계속·복귀 후 결과 표시 |
| 대상 변경·재시도 | 초안 폐기 확인, 취소·오류·시간 초과 구분, 명시적 재전송 |
| 기간 조회 정상·빈 결과 | 원본 CSV 숫자·시각과 그래프 대조, 빈 기간 안내 |
| 긴 기간·결측 | 실제 점만 축소 선택, 원본·표시 개수 구분, 결측 연결선 없음 |
| 인증·잘못된 기간·실패 | 무인증 거부, 명확한 오류와 재시도, CSV 변경 없음 |
| 헤더·자동 갱신 | 메뉴 줄 조작·상단 연결 상태·조회 화면 분리 |
| Trace/Audit | 같은 페이지 조회, 오류·빈 상태·재시도, 새 탭·다운로드 없음 |

실제 CSV·Kafka·API·Ollama·Chromium을 별도 포트와 임시 계정으로 검증한다. 사용자 실행 환경은 중단하지 않는다. 명령·응답·화면 캡처·결과를 재현 가능한 아티팩트에 저장하고 개인 키·쿠키는 기록하지 않는다. 빌드나 이전 실행 성공만으로 이번 E2E를 통과했다고 기록하지 않는다.
