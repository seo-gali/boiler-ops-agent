# BoilerOps Agent 사용 안내 영상 시나리오

처음 사용하는 사람이 로그인 → 설비·센서 탐색 → AI 드릴다운 → 기간 비교 → 예측 확인 → 승인 연습·기록까지 따라 하는 한국어 자막 영상이다. 내레이션 없이도 화면과 자막으로 이해할 수 있게 구성한다.

## 촬영 범위

- 현재 프론트엔드 빌드와 실제 118개 센서 분류를 사용한다.
- 공개 원본 CSV를 읽어 현재값·최근 추이·기간 그래프를 표시한다. 원본값·결측·단위를 바꾸지 않는다.
- 로그인·AI 답변·Simulator·Audit는 녹화 전용 메모리 응답으로 시연한다. 실제 모델 평가나 백엔드 통합 검증 영상이 아니며 영상에 시연 표시를 유지한다.
- 실제 개인 접근 키, 환경 파일, 기존 DB·질문·승인 기록은 읽거나 녹화하지 않는다. 실제 설비 연결은 없다.
- 로컬 MP4, 한국어 SRT, 챕터·타임라인, 대표 화면을 제공한다. 공개 배포와 외부 업로드는 포함하지 않는다.

## 장면 구성

| 순서 | 장면 | 화면 조작 | 자막에서 설명할 내용 |
| --- | --- | --- | --- |
| 1 | 시작 | 제목과 전체 순서 | 과거 운전 데이터를 탐색하는 앱이며 실제 설비를 제어하지 않음 |
| 2 | 실행·로그인 | `npm start` 안내 후 operator 로그인 | 접근 키는 실행 터미널에서 발급받아 입력, 영상은 시연 계정 사용 |
| 3 | 공장 모니터링 | 연결 상태·원본 시각·지도 확대·보기 초기화·설비 선택 | LIVE는 과거 CSV 재생의 수신 상태, 그림은 논리 배치 |
| 4 | 센서 상세 | 설비 목록 → 센서 상세 → 최근 2분 원본 표 | 대표값 외의 센서, 원본값·단위·시각·수신 품질 확인 |
| 5 | AI 드릴다운 | AI → 전체 설비 → 재열기 → 최종재열기 → 센서 | 탐색만으로 모델 호출하지 않음, 센서를 고르면 질문 대상 고정 |
| 6 | AI 질문·근거 | 현재값 설명 → Trace → 추이 후속 질문 | 답변의 근거와 원본 시각, 각 질문은 독립 조회, 실제 모델 대기 시간은 환경에 따라 다름 |
| 7 | 기간 비교 | 두 온도 센서 추가 → 기간 입력 → 조회 → 그래프 상세 | 같은 단위 비교, 마우스·키보드로 원본 관측 확인, 최근 2분보다 긴 기간 탐색 |
| 8 | 5분 예측 | 공장 하단 예측·시험 성능 | 예측 시각과 Naive 비교를 함께 확인, 운전 제어 판단의 근거로 단정하지 않음 |
| 9 | 승인 연습 | 재열기 질문 근거 → 제안 생성 → 값 확인 → 명시적 승인 | 연습용 값만 변경, 요청값·기존값·Revision 확인, 실제 설비 제어와 구분 |
| 10 | 기록·종료 | 변경 기록 → 로그아웃·종료 안내 | 본인 승인 결과 확인, 앱 종료는 실행 터미널에서 Enter |

자막은 한 화면에 한 가지 행동을 설명하고 실제 클릭 순서와 맞춘다. 화면 변화와 읽기 시간을 확보하며 빠른 점프 컷으로 필수 확인 단계를 생략하지 않는다. 정확한 시작·종료 시각은 녹화 결과의 `timeline.json`과 SRT에 기록한다.

## 재현과 산출물

설치된 Node.js·Python 가상환경·Playwright Chromium·FFmpeg를 사용한다. 추가 패키지 설치 없이 프로젝트 루트에서 실행한다.

```powershell
npm --prefix frontend run build
node scripts/record-user-guide.mjs
```

전체 녹화 전 `node scripts/record-user-guide.mjs --check`로 읽기 대기 시간을 줄인 사전 촬영을 검증할 수 있다. 사전 촬영은 `artifacts/user-guide/preflight/`에 분리해 저장한다.

결과는 `artifacts/user-guide/`에 저장한다. MP4에는 한국어 자막을 입히고 SRT도 별도로 제공한다. 생성된 영상·원본 CSV 발췌·중간 녹화물은 Git에 포함하지 않는다. 시나리오와 녹화 스크립트만 버전 관리한다.

검증은 필수 화면 조작·요청 Tag·승인 전후 값·자막 타임라인을 확인하고 FFprobe로 영상 길이·해상도·코덱을 검사한다. 영상의 시작·중간·끝 프레임을 추출해 한국어 자막과 UI가 보이는지도 확인한다.

`node scripts/record-user-guide.mjs`의 화면 조작·요청 검증 13개와 FFprobe 검사가 통과했다. 최종 프레임 검수에서 종료 뒤 붙은 시간을 시작 지연으로 잘못 계산한 자막 동기화 문제를 발견해 원본을 다시 인코딩했다. 재현 스크립트도 프레임의 프리롤 종료 지점으로 동기화하도록 수정하고 `--check` 사전 촬영을 다시 통과했다. 시작·지도·AI 근거·기간 그래프·승인·끝 화면에서 자막과 실제 UI가 맞는지 확인했다.

`verification.json`은 최종 영상 정보와 13개 검증 범위를 기록한다. 실제 모델 성능·백엔드 통합·운영 부하 검증을 대신하지 않는다.
