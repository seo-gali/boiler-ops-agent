# BoilerOps Agent 사용 안내 영상 시나리오

처음 사용하는 사람이 로그인부터 센서 탐색·질문·승인 연습까지 따라 하는 영상이다. 설비를 고르고 센서를 찾는 장면에서 시작해, 기간별 그래프와 AI 답변을 확인한 뒤 변경 기록을 살펴보는 순서로 구성한다. 음성 설명 없이도 따라 할 수 있도록 한국어 자막을 넣는다.

## 촬영 범위

앱 화면과 실제 118개 센서 분류를 사용한다. 값과 그래프는 공개 원본 CSV에서 읽으며, 비어 있는 값과 단위를 임의로 바꾸지 않는다.

로그인·AI 답변·승인 연습·변경 기록은 촬영용 응답으로 보여준다. 실제 모델과 서버를 연결해 성능을 검증한 영상은 아니다. 이 점을 영상에 표시하고 실제 개인 키·환경 파일·기존 사용자 기록은 촬영하지 않는다.

촬영 스크립트는 MP4 영상, 별도 SRT 자막, 장면별 시간표와 대표 이미지를 만든다. 외부 서비스에 업로드하는 기능은 없다.

## 장면 구성

| 순서 | 장면 | 화면 조작 | 자막에서 설명할 내용 |
| --- | --- | --- | --- |
| 1 | 시작 | 제목과 전체 순서 | 과거 운전 데이터를 탐색하는 앱이며 실제 설비를 제어하지 않음 |
| 2 | 실행·로그인 | `npm start` 안내 후 operator 로그인 | 접근 키는 실행 터미널에서 발급받아 입력, 영상은 시연 계정 사용 |
| 3 | 공장 모니터링 | 연결 상태·원본 시각·지도 확대·보기 초기화·설비 선택 | LIVE는 과거 CSV를 받아 오는 상태이며 그림은 센서를 찾기 위한 배치 |
| 4 | 센서 상세 | 설비 목록 → 센서 상세 → 최근 2분 원본 표 | 대표값 외의 센서, 원본값·단위·시각·수신 품질 확인 |
| 5 | AI에서 센서 찾기 | AI → 전체 설비 → 재열기 → 최종재열기 → 센서 | 목록을 둘러볼 때는 AI가 답변을 생성하지 않으며 센서를 고르면 질문 대상이 정해짐 |
| 6 | AI 질문·근거 | 현재값 설명 → 조회 기록 → 변화 이어 묻기 | 답변의 근거와 원본 시각, 질문마다 별도로 조회하며 실제 대기 시간은 환경에 따라 다름 |
| 7 | 기간 비교 | 두 온도 센서 추가 → 기간 입력 → 조회 → 그래프 상세 | 같은 단위 비교, 마우스·키보드로 원본 관측 확인, 최근 2분보다 긴 기간 탐색 |
| 8 | 5분 예측 | 공장 하단 예측·시험 결과 | 예측 시각과 현재값을 유지하는 단순 예측(Naive)의 오차 비교, 실제 조작 판단에 사용하지 않음 |
| 9 | 승인 연습 | 재열기 질문 근거 → 제안 생성 → 값 확인 → 사용자 승인 | 연습용 값만 바뀌며 요청값·기존값·변경 횟수(Revision)를 확인 |
| 10 | 기록·종료 | 변경 기록 → 로그아웃·종료 안내 | 본인 승인 결과 확인, 앱 종료는 실행 터미널에서 Enter |

자막 하나에는 행동 하나만 설명한다. 실제 클릭 순서에 맞추고 화면과 글을 읽을 시간을 둔다. 중요한 확인 장면을 빠른 편집으로 건너뛰지 않는다. 각 장면의 시작·종료 시각은 `timeline.json`과 SRT에 기록한다.

## 재현과 산출물

설치된 Node.js·Python 가상환경·Playwright Chromium·FFmpeg를 사용한다. 추가 패키지 설치 없이 프로젝트 루트에서 실행한다.

```powershell
npm --prefix frontend run build
node scripts/record-user-guide.mjs
```

전체 촬영 전에는 `node scripts/record-user-guide.mjs --check`로 화면을 짧게 녹화해 확인할 수 있다. 이 사전 촬영 결과는 `artifacts/user-guide/preflight/`에 따로 저장한다.

결과는 `artifacts/user-guide/`에 저장한다. MP4에는 한국어 자막을 입히고 SRT도 별도로 제공한다. 생성된 영상·원본 CSV 발췌·중간 녹화물은 Git에 포함하지 않는다. 시나리오와 녹화 스크립트만 버전 관리한다.

촬영 뒤에는 화면 조작, 조회한 센서의 원본 이름(Tag), 승인 전후 값과 자막 시간을 확인한다. FFprobe로 영상 길이·해상도·코덱을 검사하고 시작·중간·끝 이미지를 뽑아 자막과 화면이 잘 보이는지도 살핀다.

`node scripts/record-user-guide.mjs`의 화면 조작·요청 검증 13개와 FFprobe 검사가 통과했다. 최종 프레임 검수에서 종료 뒤 붙은 시간을 시작 지연으로 잘못 계산한 자막 동기화 문제를 발견해 원본을 다시 인코딩했다. 재현 스크립트도 프레임의 프리롤 종료 지점으로 동기화하도록 수정하고 `--check` 사전 촬영을 다시 통과했다. 시작·지도·AI 근거·기간 그래프·승인·끝 화면에서 자막과 실제 UI가 맞는지 확인했다.

`verification.json`은 최종 영상 정보와 13개 검증 범위를 기록한다. 실제 모델 성능·백엔드 통합·운영 부하 검증을 대신하지 않는다.
